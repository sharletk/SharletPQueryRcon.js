# SharletPQueryRcon.js
A Query and Rcon Client for Minecraft Bedrock Servers in Node.js

### Version
1.0.0

## Installation
```
npm i github:sharletp/SharletPQueryRcon.js
```

[Query Example](examples/query/index.js)

[Rcon Example](examples/rcon/index.js)
